㈜누리소프트 2024년 하반기 신입 공개채용 자기소개서
지원 직무: 백엔드 개발
지원자: 김민준 (가상의 인물 · Essay 테스트용 예시)

1. 지원 동기와 입사 후 포부를 작성해 주세요. (공백 포함 700자 이내)

저는 한국대학교 컴퓨터공학과 4학년(2025년 2월 졸업 예정, 학점 3.72/4.5)으로, 사용자가 체감하지 못하는 곳에서 서비스를 안정적으로 떠받치는 백엔드 개발에 매력을 느껴 지원했습니다. 학부 시절 Spring Boot와 MySQL로 교내 중고거래 서비스 '캠퍼스마켓'을 만들어 실제 사용자 1,200명을 받아 본 경험이 있습니다. 트래픽이 몰리던 개강 첫 주에 서버가 두 번 멈췄고, 그때 처음으로 커넥션 풀과 인덱스 설계를 공부하며 "돌아가는 코드"와 "버티는 코드"가 다르다는 것을 배웠습니다. 누리소프트는 공공기관 민원 시스템을 20년 넘게 운영하며 장애 대응 체계를 공개적으로 공유해 온 회사입니다. 입사 후에는 모니터링과 장애 분석 역량을 먼저 키워, 3년 안에 운영 중인 서비스의 평균 응답 시간을 눈에 띄게 줄이는 개발자가 되고 싶습니다. 정보처리기사(2024년 6월 취득)와 SQLD(2024년 3월 취득)를 준비하며 다진 기본기를 현장에서 증명하겠습니다.

2. 공동의 목표를 위해 다른 사람과 협업했던 경험을 작성해 주세요. (공백 포함 1,000자 이내)

2024년 3월부터 6월까지 교내 소프트웨어 학회 'CodeLab'에서 4명이 팀을 이뤄 캠퍼스마켓 서비스를 개발했습니다. 저는 백엔드와 배포를 맡았습니다. 개발 한 달째, 프론트엔드 팀원과 API 명세가 계속 어긋나 하루에도 몇 번씩 서로의 코드를 고치는 일이 반복됐습니다. 원인은 명세를 말로만 주고받은 데 있었습니다. 저는 Swagger로 API 문서를 자동 생성하고, 변경이 생기면 반드시 문서를 먼저 고친 뒤 코드를 바꾸자는 규칙을 제안했습니다. 처음에는 "문서 쓸 시간에 코드를 쓰자"는 반대도 있었지만, 일주일 시범 운영 뒤 통합 테스트에서 나던 오류가 주당 11건에서 2건으로 줄자 모두 동의했습니다. 또한 매일 저녁 15분 짧은 공유 회의를 열어 막힌 부분을 바로 꺼내도록 했습니다. 그 결과 예정보다 일주일 빠른 5월 말에 서비스를 열었고, 개강 후 한 달 만에 가입자 1,200명, 거래 글 3,400건을 기록했습니다. 이 경험으로 협업의 속도는 소통의 양이 아니라 "같은 것을 보고 있는가"에서 나온다는 것을 배웠고, 지금도 어떤 작업이든 문서와 인터페이스를 먼저 맞추는 습관이 생겼습니다.

3. 도전적인 목표를 세우고 노력했던 경험을 작성해 주세요. (공백 포함 800자 이내)

2023년 여름방학, 스타트업 '모두의배달'에서 8주간 서버 개발 인턴으로 일했습니다. 입사 첫 주에 받은 과제는 주문 조회 API 하나였지만, 저는 "이 API가 느리다"는 운영팀의 불만을 듣고 응답 시간을 절반으로 줄이는 것을 스스로 목표로 세웠습니다. 로그를 분석해 보니 주문 하나를 조회할 때 배달원 정보를 매번 다시 가져오는 N+1 문제가 있었고, 평균 응답 시간이 1.8초였습니다. 저는 쿼리를 JOIN FETCH로 바꾸고 자주 조회되는 배달원 정보를 Redis에 5분간 캐시했습니다. 변경 전후를 같은 조건에서 측정하기 위해 JMeter로 부하 테스트 스크립트를 만들었고, 그 결과 평균 응답 시간을 1.8초에서 0.4초로 줄였습니다. 멘토 개발자분이 이 스크립트를 팀의 성능 테스트 기본 도구로 채택해 주신 것이 가장 뿌듯했습니다. 목표를 조금 높게 잡고 측정 가능한 숫자로 바꾸는 습관이 이때 생겼습니다.

4. 본인의 성장 과정과 가치관에 대해 작성해 주세요. (공백 포함 500자 이내)

고등학교 때 학급 신문을 만들며 "독자가 읽기 쉬운가"를 끝까지 따지던 습관이 지금은 "사용하는 사람이 편한가"로 이어졌습니다. 대학에서는 2022년 한 해 동안 지역 아동센터에서 주 1회 코딩 교육 봉사를 했는데, 아이들이 이해하지 못하면 제 설명이 틀린 것이라고 생각하며 설명을 세 번씩 바꿔 보곤 했습니다. 저에게 좋은 개발자란 어려운 기술을 아는 사람이 아니라, 그 기술을 쓰는 사람과 함께 일하는 동료가 편해지게 만드는 사람입니다. 2024년 5월 TOEIC 880점을 받은 것도 영어 문서를 막힘없이 읽어 팀에 빨리 공유하고 싶었기 때문입니다.
