# 티오(TIO) 기능 분석

2026-10-08, 로그인 상태에서 직접 조작하며 확인한 내용. 취준노트에 옮길 때의 기준 문서.
(질문 은행·문구는 티오의 콘텐츠라 그대로 가져오지 않고 구조만 참고)

## 전체 구조

```
온보딩(5단계) → 홈(공고 링크 입력) → 프로젝트(=공고 1개) 에디터
                                      ├ 채용 공고 / 인사이트
                                      ├ 서류: 이력서 / 자기소개서
                                      ├ 면접: 면접 준비 / 면접 복기
                                      └ 커리어: 경험 관리 / 지원 현황
```

- 전역 사이드바: 새로 시작하기 / 프로젝트 / 경험 관리 / 최근 프로젝트 / 프로필(Free·업그레이드)
- 무료: AI 기능 하루 5회. 기업 분석은 Pro 전용

## 1. 온보딩

| 단계 | 내용 |
| --- | --- |
| 1 | 준비 활동: 대외활동 / 인턴·계약직 / 취업 준비 / 이직 |
| 2 | 기업 종류(복수): 대기업 / 중견·중소 / 공기업 / 스타트업 / 외국계 |
| 3 | 관심 직군 → 관심 직무 2단계 선택 (직군 20개, 직군별 직무 수십 개) |
| 4 | 최종 학력(대학교 4년제 등) → 학교명, 졸업 상태(졸업/졸업 예정/재학 중/중퇴/수료/휴학), 입학·졸업 연월, 전공 및 학위, 학점(만점 4.5/4.3/4.0) — 건너뛰기 가능 |
| 5 | 약관 동의 |

→ 직군은 홈의 "인기 공고" 필터, AI 피드백의 맥락("기계 엔지니어는…", "대기업 평가자는…")에 쓰인다.

## 2. 홈 / 프로젝트 생성

- 헤드라인 "오늘은 어떤 [자소서|이력서]를 준비해 볼까요?" (단어 회전)
- 공고 URL 입력 → 자동 파싱 / **링크 없이 시작하기** / **지원할 공고 찾기**
- 🔥 이번 달 인기 공고 (직군 필터, 카드: 회사·포지션·D-day·마감일·N명 지원 중·시작하기)
- 링크 없이 시작 → "공고 가져오기": 캡처 붙여넣기(여러 장) / PDF·이미지 / 직접 입력
- 직접 입력 폼: 기업명* / 지원 포지션* / 마감일 / 공고 내용(소제목+내용 섹션, 추가·삭제·초기화)
- 공고 확인 화면: 파싱된 섹션(직무 개요·담당 업무·자격 요건·복리후생·채용 절차·기타), 공고 원문 보기, "공고 정확하게 불러오기"
- 문항 설정: 회사 실제 문항 자동 입력(문항 + 글자수), 최대 15개, "자유 문항 불러오기"

## 3. 자기소개서 에디터 (핵심)

**가운데 – 문서**
- 상단 Q1 Q2 Q3 Q4 + 탭, 모든 문항이 세로로 이어진 한 문서
- 문항 헤더: `681자 / 700자 · 1192 byte`
- 문항 툴바: 카운터 설정 / 내용 복사 / 편집 기록(내용 복원) / 실행 취소·다시 실행 / 문항 메뉴
- 카운터 설정: 기준 = 글자 수 | 한글 2byte | 한글 3byte, 공백 포함 토글
- 실측: 문단 바꿈 1개 = 1자 = 1byte, 한글 2byte, 영문·공백 1byte
- 답변 첫 줄에 `[소제목]` 형식

**오른쪽 – 패널 4탭: 채팅 / 인사이트 / 메모 / 친구첨삭**

채팅 (초안 흐름)
1. "어떤 경험을 중심으로 작성할까요? (최대 2개)" — 문항에 맞는 내 경험 추천(체크), 직접 추가, STARI 예시
2. 진행 표시: 어필 포인트 찾기 → 인재상 파악 → 방향성 → 논리 흐름 → 초안 작성 (본문에 스트리밍)
3. 작성 의도 설명(서론/본론/결론 설계 이유) + "조금 길게 썼어요, 같이 다듬을까요?"
4. 빠른 동작: 초안작성 / 피드백받기 / 소제목추천 / 맞춤법검사 / 휴머나이징
- 피드백: 대상 선택(종합 / Q1~Qn, 빈 문항 비활성) → 항목별 코멘트(지원동기·경험 연결·입사 후 계획), **공고에 없는 사실 지적**, 글자수 초과 지적, 출처 표기
- 후속 선택지: ① 피드백 반영해 고쳐줘(추천) ② ③ 구체 수정 지시 / 기타 / 건너뛰기
- 수정 모달: [전체 수정 | 부분 수정] — 전체는 좌(원문)·우(수정본 하이라이트) + `895 → 684자 (-211)`, 부분은 문장 단위 원문→제안 카드를 골라 반영, 일괄 수정 / 닫기·적용하기
- 채팅: 새 채팅, 채팅 기록, 모델 선택, 메시지 복사·다시 생성

인사이트 (4개 하위 탭)
- 직무 분석: 하는 일(항목 + 한마디로) / 해결하는 문제(핵심 과제·존재 이유·면접 어필 포인트) / 요구 역량 표(Technical·Domain·Soft × 필수·우대) / 원하는 인재상(한마디로 + 행동 특성) / 공고 핵심 키워드와 그 의미
- 문항 분석: 문항별 글자수 · 문항 의도 · 평가 포인트 3개(제목 + 점검 질문) · 작성 방향성 3~4개
- 기업 분석(Pro): 사업 내용 · 재무(3개년 표, 지표, 차트) · 경쟁사·포지셔닝 · SWOT 및 활용점 · 최근 이슈, DART·뉴스 출처
- 지원 전략: 자소서 어필 포인트(어필 전략 + 이런 경험이 있다면) · 차별화 키워드 · 면접용 핵심 사업 맥락 · 예상 질문 & 답변 포인트·근거

메모: 노션식 블록 에디터(/ 명령)
친구첨삭: 공유 링크 → 친구가 문장에 수정 제안·댓글, 수락/거절

## 4. 경험 관리

- 시작 방식: 파일 업로드(이력서·포트폴리오·자소서에서 추출) / Notion 연동 / 질문에 답하며 정리하기
- Q&A 정리 흐름
  1. Q1 어떤 활동? (한 줄 설명, 예시 불러오기)
  2. Q2 AI가 활동에서 소재 후보 6개 생성 → 최소 3개 선택(직접 추가 가능)
  3. 소재마다 "어떤 행동 → 어떤 결과" 선택지 4개 생성 → 1개 선택
  4. 결과: 활동 1개 아래 소재 N개, 각 소재 = 이모지 + `[역량] 제목` + 행동·결과·배운 점
- 화면 3단: 연도별 타임라인(연도 → 활동 → 소재 카드, 역량 태그) / 소재 상세 / AI 채팅
- 보기: 트리뷰(마인드맵, 줌) / 디렉토리뷰 / 카드뷰 / 검색
- 소재 상세 필드: 아이콘, 제목, 역량 태그(자유), 경험유형 태그, Situation 배경·상황 / Task 역할·과제 / Action 행동 / Result 결과 / Insight 배운 점 / 메모
- 경험유형 프리셋 10개: 리더십·주도, 협업, 갈등조정, 소통·설득, 문제해결·분석, 효율 개선, 기획·창의, 도전·성취, 실패·회복, 성장·학습
- AI에게 요청하기: 보충하기 / 다듬기 / 피드백 / 분석 → 필드별 취소선·하이라이트 diff, 하단 바 `1/4 · 거절 · 수정 · 일괄 수정`
- 채팅 추천 질문: 직무에 맞는 경험은? / 부족한 점은? / 내 강점은?

## 5. 이력서

- 직접 작성 / 파일 업로드, 언어 선택(한국어), 새로 만들기, PDF 다운로드
- 섹션: 이름·연락처·이메일·증명사진 / 소개(1~3줄) / 경력(기간·재직형태·직무·직책·주요 성과 bullet, **경험 불러오기**) / 학력 / 수상·자격·기타활동(연월·분류) / 언어(어학시험 추가) / 스킬 / 링크
- AI: 이력서 점검 / 피드백 받기 / 맞춤법검사, 추천 질문(공고 대비 보완점, 강조 포인트, 소개 문구 다듬기, 약점)

## 6. 면접

- 면접 준비: 공통 질문 / 맞춤 질문(자소서 기반), PDF
  - 공통 카테고리: 필수 / 직무 적합성 / 조직 적합성 / 위기 대처, 질문 추가, 답변 요약 토글
  - 질문 카드: 답변 칸 + 꼬리질문 만들기
  - 패널: 답변 만들기(경험·자소서 기반) / 피드백 받기(인사·실무 관점)
- 면접 복기: 면접 유형(직무/임원/AI/직접 작성)* · 면접일 · 메모(200자: 면접관 수, 직책, 분위기) → 질문·답변 기록

## 7. 지원 현황 (= 프로젝트 목록)

칸반: 작성 중 → 지원 여부(제출 완료 / 미제출) → 서류 전형 → 1차 전형 → 2차 전형 → 최종 결과, 각 전형은 합격/불합격 칸, 드래그로 이동, 카드에 마감일 설정
