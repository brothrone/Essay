Windows용 Essay를 내려받는 중…

받는 동안 1분만 읽어 주세요.
처음 실행할 때 한 번, 이 안내가 필요해요.

Essay는 아직 Microsoft 코드 서명을 받지 않은 개인 배포 앱이에요. 그래서 설치 파일을 처음 실행하면 파란 창으로 "Windows의 PC 보호" 라고 막아요. 바이러스가 아니라 서명이 없어서 뜨는 안내이고, 아래 순서대로 한 번만 넘기면 설치되고 다음부터는 바로 열려요.

파일: Essay-Setup.exe 다운로드가 시작되지 않으면 여기

Windows 10 / 11 (64비트) 용이에요. Mac 이면 Mac 설치 안내로 가세요.

설치하고 처음 여는 법

3분이면 끝나요. 2번 파란 창에서 "추가 정보"를 먼저 눌러야 실행 버튼이 나오는 것만 기억하세요.

  1. 받은 Essay-Setup-<버전>.exe 를 더블클릭

    브라우저 오른쪽 위 다운로드 목록이나 다운로드 폴더에 있어요. 브라우저가 "일반적으로 다운로드되지 않는 파일" 이라고 하면 유지(또는 "그래도 다운로드")를 누르세요. 같은 이유(서명 없음)로 뜨는 안내예요.

  2. 파란 "Windows의 PC 보호" 창 → 작은 글씨 "추가 정보" → "실행"

    처음엔 [실행 안 함] 버튼만 보여요. 창 가운데 작은 글씨 "추가 정보" 를 누르면 아래에 [실행] 버튼이 나타나요. 그걸 누르세요.

    Windows의 PC 보호

    Microsoft Defender SmartScreen이 인식할 수 없는 앱의 시작을 차단했습니다. 이 앱을 실행하면 PC가 위험에 노출될 수 있습니다.

    추가 정보 먼저 이걸 누르세요

    앱: Essay-Setup.exe
    게시자: 알 수 없는 게시자

    실행 그다음 이걸
    실행 안 함
  3. 잠깐 기다리면 설치가 끝나고 Essay 가 바로 열려요

    물어보는 것 없이 작은 진행 창이 떴다가 사라지고 Essay 가 열려요. 바탕화면과 시작 메뉴에 Essay 아이콘이 생겨요. "사용자 계정 컨트롤" 창이 뜨면 예.

  4. 처음 켜면 뜨는 안내를 따라 AI 연결

    Claude 또는 Gemini 를 고르고 [설치] → [로그인] 을 누르면 Essay 안에서 진행돼요. 나중에 해도 되고, AI 없이 먼저 써 봐도 돼요. 막히면 앱에서 F1.

"추가 정보" 글씨가 안 보이면

회사 PC 처럼 보안 정책이 걸린 경우예요. 받은 파일을 마우스 오른쪽 클릭 → 속성 → 맨 아래 "차단 해제" 에 체크 → 확인 → 다시 실행해 보세요. 그래도 안 되면 PC 관리자에게 물어보세요.

궁금한 것

왜 이런 창이 뜨나요? 위험한 앱인가요?

Windows 는 Microsoft 에 등록한 서명이 있는 앱만 바로 실행해 줘요. Essay 는 개인이 무료로 배포하는 앱이라 아직 서명을 받지 않았고, 그래서 "인식할 수 없는 앱" 이라고 뜨는 거예요. 앱이 하는 일은 소개 페이지에 그대로 적혀 있고, 데이터는 내 PC 의 문서 폴더 밖으로 나가지 않아요. 코드도 GitHub 에 공개돼 있어요.

매번 해야 하나요?

아니요. 설치할 때 한 번만이에요. 새 버전은 앱이 스스로 내려받아 다음에 켤 때 조용히 적용되니 다시 받을 일도 없어요.

어디에 설치되나요?

내 계정 폴더 안(AppData\Local\Programs\Essay)에 설치돼서 관리자 권한이 필요 없어요. 내 글은 문서\Essay 폴더에 파일 하나로 저장돼요.

Essay 를 지우고 싶어요

Windows 설정 → 앱 → Essay → 제거. 내 글이 든 파일(문서\Essay)은 지워지지 않아요.
